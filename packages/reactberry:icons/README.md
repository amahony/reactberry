# @reactberry/icons

`@reactberry/icons` is a Reactberry-owned private/deferred package boundary for named icon exports.

- Status: internal workspace package boundary only; not part of the first public Reactberry release.
- Current internal surface: initial small chevron icons only; no app-specific icon sets.
- Contract guardrail: use explicit named exports; do not add dynamic icon-loading patterns or app-coupled imports.
- Release posture: keep this package repo-local/private and do not document or publish it as a supported consumer entrypoint for the first release.
