# @reactberry/forms

`@reactberry/forms` is an approved initial public package surface for the Reactberry hard-break release.

- Status: public package boundary for reusable form controls and form-facing primitives.
- Consumer contract: import from `@reactberry/forms` and related supported package roots only; do not rely on `/src` or `/dist` deep imports.
- Dependency posture: `forms` is the form layer that builds on `@reactberry/core` rather than a separate placeholder surface.
