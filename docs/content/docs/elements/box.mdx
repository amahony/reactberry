`Box` is a styled `div` built with styled-components and styled-system. Every other element (`Text`, `Button`, `Field`) extends it, so the props on this page are available everywhere.

## Import

```tsx
import { Box } from "@reactberry/system/elements";
```

## Basic usage

```tsx
<Box display="flex" alignItems="center" gap="s" p="m" skin="card" shape="rounded">
  <Text>Content</Text>
</Box>
```

## Style props

`Box` composes these styled-system groups. Values resolve against the theme where a scale exists, otherwise they pass through as raw CSS.

- `color` — `color`, `bg` / `backgroundColor`, `opacity`; maps to `theme.colors`
- `space` — `m`, `p` and their directional variants (`mt`, `px`, and so on); maps to `theme.space`
- `layout` — `width`, `height`, `minWidth`, `maxWidth`, `size`, `display`, `overflow`, `verticalAlign`; `size` maps to `theme.sizes`
- `flexbox` — `alignItems`, `justifyContent`, `flexDirection`, `flex`, `flexWrap`, `order`, and related props
- `grid` — `gridTemplateColumns`, `gridArea`, `gridGap`, and related props
- `position` — `position`, `top`, `right`, `bottom`, `left`, `zIndex`
- `background` — `backgroundImage`, `backgroundSize`, `backgroundPosition`, `backgroundRepeat`
- `border` — `border`, `borderColor`, `borderWidth`, `borderRadius`, and directional variants
- `shadow` — `boxShadow`, `textShadow`

`Box` does not apply typography props such as `fontSize`, `fontWeight`, or `lineHeight`. Use `Text` for those.

## Reactberry props

- `gap` — CSS `gap`, maps to `theme.space`
- `skin` — applies a style object from `theme.skins` (background, border, and text colour together)
- `shape` — border radius from `theme.shapes`
- `$size` — height and padding from `theme.controlSizes`
- `$shadow` — shadow from `theme.shadows`
- `aspect` — CSS `aspect-ratio`
- `cursor` — CSS `cursor`
- `transform` — CSS `transform`
- `placeItems` — CSS `place-items` shorthand
- `hover` — a skin path from `theme.skins`, applied under `:hover`
- `focus` — a skin path from `theme.skins`, applied under `:focus` and `:focus-within`
- `interactive` — raw style props per state (see below)
- `disabled` — sets `opacity: 0.5` and `pointer-events: none`
- `as` — render a different element or component

## Theme tokens

Space aliases (`theme.space`):

- `mini` 0.125rem, `xxxs` 0.25rem, `xxs` 0.375rem, `xs` 0.5rem, `s` 0.75rem, `m` 1rem, `l` 1.5rem, `xl` 2rem, `xxl` 2.5rem, `xxxl` 3rem
- Long names (`xsmall`, `small`, `medium`, `large`, `xlarge`) match the short ones; `xxlarge` is 3rem and `xxxlarge` is 4rem

Size aliases for `size` (`theme.sizes`):

- `xs` 0.5rem, `s` 0.75rem, `m` 1rem, `l` 1.125rem, `xl` 1.25rem

Shapes (`theme.shapes`):

- `square` 0px, `roundedSmall` 4px, `rounded` 8px, `roundedLarge` 16px, `pill` 32px, `circle` 50%
- `roundedTop`, `roundedBottom`, `roundedLeft`, `roundedRight` round one side by 6px

Control sizes for `$size` (`theme.controlSizes`):

- `xxxsmall` — height 1.5rem, padding 0.125rem 0.5rem
- `xxsmall` — height 1.75rem, padding 0.125rem 0.5rem
- `xsmall` — height 2rem, padding 0.25rem 0.75rem
- `small` — height 2.25rem, padding 0.25rem 0.75rem
- `medium` — height 2.5rem, padding 0.5rem 1rem
- `large` — height 3rem, padding 0.5rem 2rem
- `xlarge` — height 4rem, padding 0.5rem 2.5rem

Shadows for `$shadow` (`theme.shadows`):

- `xxsmall`, `xsmall`, `small`, `medium`, `large`

## Skins

Skins resolve by dot path, so nested entries are available as `card.shade` or `translucent.dark`. The default light theme includes:

- Surfaces — `base`, `surface`, `panel`, `card`, `overlay`, each with `.shade` and `.tint`
- Signals — `error`, `success`, `warning`, `info`, `brand`, `accent`, `neutral`
- Colour pairs — `red`, `orange`, `yellow`, `green`, `teal`, `blue`, `purple`, `pink`, `gray`, `primary`
- States — `highlight`, `focused`, `minimal`, `outlined`
- Special — `transparent`, `translucent` (with `.light`, `.dark`, `.yellow`), `gradient`, `contrast`
- Hover — `hover.default`, `hover.subtle`, `hover.dim`, `hover.brand`, `hover.error`, `hover.info`, `hover.warning`, `hover.success`, `hover.contrast`, `hover.lighten`, `hover.accent`

The dark theme defines a smaller set. Check `src/themes/default/modes/dark/skins.js` before relying on a specific key.

## Interactive states

`hover` and `focus` take a skin path:

```tsx
<Box skin="card" p="m" shape="rounded" hover="hover.subtle" focus="highlight" tabIndex={0}>
  Card
</Box>
```

For raw styles, use `interactive`. Keys are `hover`, `focus`, `focusWithin`, `focusVisible`, `active`, `disabled`, and `visited`; camelCase keys become pseudo-classes such as `:focus-within`. Values accept the same style props as `Box`, including `skin` and `shape`.

```tsx
<Box
  p="m"
  skin="surface"
  interactive={{
    hover: { bg: "palette.brands.0", transform: "translateY(-2px)" },
    focusVisible: { boxShadow: "0 0 0 2px currentColor" },
  }}
/>
```

## Responsive values

All style props accept arrays or breakpoint objects. Breakpoint keys are `xs`, `sm`, `md`, `lg`, and `xl`, with `_` as the base.

```tsx
<Box p={["s", "m", "l"]} display={{ _: "block", md: "flex" }} gap="m" />
```

## Notes

- Use `size` (or `width` / `height`) for dimensions. `$size` applies control height and padding.
- Prefer theme aliases (`p="m"`) over raw values (`p="16px"`).
