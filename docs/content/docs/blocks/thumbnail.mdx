`Thumbnail` is a client component (`"use client"`) that renders a relatively positioned, `overflow="hidden"` `Box` containing a `next/image` in `fill` mode. It requires Next.js.

## Import

```tsx
import { Thumbnail } from "@reactberry/system/blocks";
```

## Usage

```tsx
import { Thumbnail } from "@reactberry/system/blocks";
import { Box, Text } from "@reactberry/system/elements";

export default function ArticleCard() {
  return (
    <Box skin="surface" shape="rounded" overflow="hidden">
      <Thumbnail
        src="https://example.com/covers/launch.jpg"
        alt="Launch event stage"
        width="100%"
        aspect="16/9"
      />
      <Box p="m">
        <Text fontWeight="600">Launch recap</Text>
      </Box>
    </Box>
  );
}
```

## Props

- `src` (`string`, required) — image URL passed to `next/image`.
- `alt` (`string`, required) — image alt text.
- `objectFit` (`"cover" | "contain" | "fill" | "none" | "scale-down"`, default `"cover"`) — passed to the image element.
- All other `BoxProps` except `as` are spread onto the wrapper `Box`.

## Examples

Fixed square thumbnail:

```tsx
<Thumbnail src={user.photoUrl} alt={user.name} size="4rem" shape="rounded" />
```

## Notes

- The image uses `fill`, so the wrapper must have a size: set `width` and `height`, `size`, or `width` plus `aspect`. Without one, the wrapper collapses to zero height.
- `sizes` is fixed at `"100rem"`, so Next.js may request a larger image than the rendered size. It cannot be overridden through props.
- `objectFit` is forwarded as a prop to `next/image` rather than applied as a CSS style. Current versions of `next/image` treat `objectFit` as a legacy prop, so the value may not take effect; verify the rendered result or apply `object-fit` via CSS.
- No other `next/image` props (such as `priority`, `quality` or `placeholder`) can be passed through; extra props go to the wrapper.
- Remote `src` hosts must be allowed in your Next.js `images` configuration.
