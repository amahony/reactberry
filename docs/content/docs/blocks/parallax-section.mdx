`ParallaxSection` is a client component that renders a `100vh` `section` with a darkened `next/image` background that shifts from `-20%` to `20%` as the section scrolls past. It depends on `motion/react` and `next/image`.

## Import

```tsx
import { ParallaxSection } from "@reactberry/system/blocks";
```

## Usage

```tsx
import { ParallaxSection } from "@reactberry/system/blocks";
import { Box, Text } from "@reactberry/system/elements";

export default function Overview() {
  return (
    <ParallaxSection
      image="/images/overview.jpg"
      content={
        <Box
          position="relative"
          zIndex={1}
          height="100%"
          display="flex"
          alignItems="center"
          justifyContent="center"
        >
          <Text as="h2" fontSize="xxxl" fontWeight="700" color="white">
            Built for every season
          </Text>
        </Box>
      }
    />
  );
}
```

## Props

- `image` (`string`, required) — background image source passed to `next/image`.
- `content` (`React.ReactNode`) — rendered inside the section, before the background layer.

No other props are accepted or spread. `children` is not supported; use `content`.

## Notes

- The background layer is absolutely positioned with `zIndex` 0. Give `content` a positioned wrapper (for example `position="relative"` with `zIndex` 1) so it renders above the image.
- The background layer is 120% of the section height and its `top` is driven by `useScroll` with offset `["start end", "end start"]`.
- A fixed `rgba(0, 0, 0, 0.3)` overlay is drawn above the image. There is no prop to change it.
- The image uses `fill`, `sizes="100vh"`, `objectFit: "cover"` and a fixed `alt="Overview"`.
- The section height is fixed at `100vh` with `overflow: hidden`.
- There is no reduced-motion handling.
- Remote image URLs must be allowed in your Next.js `images` configuration.
