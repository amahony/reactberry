# Getting Started

Use this page as the first stop for building out the new docs experience.

## Recommended flow

1. Read the [Documentation intro](/docs)
2. Review the [Guides intro](/guides)
3. Add new docs pages inside `docs/content/docs`
4. Add new walkthroughs inside `docs/content/guides`

## Content locations

- `docs/content/docs` for documentation pages
- `docs/content/guides` for longer-form guides
- `docs/config/docs.ts` for navigation metadata

## Writing pages

You can author pages in Markdown or MDX.

Because the renderer is mapped to Reactberry primitives, MDX pages can gradually adopt design-system components where that helps explain usage.

## Next step

If you are extending the site structure, the next useful page to expand is the guides intro so readers understand what belongs in guides versus core documentation.
