This docs app is intentionally separate from the package source so the site can have its own content structure, landing pages, and narrative flow without forcing the same shape onto `src`.

## What you will find here

- an overview path for installation and first setup
- a foundations section for theming
- an elements section for foundational items
- a blocks section for composed reusable structures
- a guides section for longer walkthroughs and implementation notes

## How to use this site

Start with [Getting started](/docs/getting-started) if you want the fastest path into the system.

Then move into [Theming](/docs/foundations/theming), [Elements](/docs/elements), and [Blocks](/docs/blocks) as you move from setup into composition.

Then move to [Guides](/guides) when you want broader explanations, workflows, and patterns.

## Principles

- the docs UI is built with Reactberry
- content is sourced from `docs/content`
- documentation content is curated separately from the package source files
