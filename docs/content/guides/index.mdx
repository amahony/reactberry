# Guides

The guides section is for narrative documentation.

Unlike short reference-style docs pages, guides should explain *why* something exists, when to use it, and how pieces fit together across the system.

## Use guides for

- onboarding flows
- multi-step implementation walkthroughs
- architecture and workflow explanations
- best practices and migration notes

## Relationship to documentation

Use the main [Documentation](/docs) section for focused reference pages.

Use guides when the reader needs context, sequence, and decision-making help rather than just a single factual page.

## Next additions

Good future guide candidates include migration notes, accessibility workflows, and theming walkthroughs.
